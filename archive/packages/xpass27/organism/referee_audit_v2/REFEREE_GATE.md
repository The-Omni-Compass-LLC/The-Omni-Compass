# Omni-Compass Complete Organism Referee Gate V2

## Status
The historical 699-row Audit-V1 catalog is a CANDIDATE INVENTORY, not 699 proven/admitted muscles.

A row may be counted in complete-organism N only when all mandatory fields below are concrete and reviewable:

1. plant/system of record
2. authority surface / actuator
3. exact command or control interface
4. units/mode and legal domain
5. preconditions / ownership / interlocks
6. independent current-state readback
7. refusal / saturation / partial-enforcement behavior
8. measurable plant consequence
9. restoration / native handback procedure
10. benchmark adapter or reproducible simulator
11. evidence class E0-E4
12. authoritative source or raw execution receipt

Names, telemetry fields, recommendations, alerts, metrics, policies without actuation, parameter values of an existing authority, and aliases do not count as new muscles.

## Benchmark scale formula
Let N be the final number of admitted, deduplicated distinct muscle contracts.
Breadth: 1 -> 10 -> 100 -> N.
Hierarchical replication after complete breadth: N -> 10N -> 100N -> 1000N -> 10000N -> ... .
Values above N are active muscle instances, not new muscle types.

## Benchmark publication discipline
- frozen Omni mechanism and hash guard
- paired identical plant/workload/seed: native vs native+Omni
- no benchmark-special retuning after confirmatory registration
- all performance-relevant configuration disclosed
- repeated confirmatory runs and distributional statistics
- raw telemetry, commands, readbacks, failures and restore receipts retained
- null/adverse/timeouts published, not deleted
- simulated/modelled/physical metrics labeled separately
- independent reproduction lane
- external audit-ready Full Disclosure Report
