## For Black Duck, FOSSA and Snyk users

These are third-party software composition analysis (SCA) products. **No vendor approval, active integration, paid subscription, successful scan, or certification is asserted by this document.** Each scanner may classify a custom LicenseRef as unknown or require a custom-license policy. Review the scanner's detected package boundaries and attach the complete LICENSE text to its custom-license record.

- **Black Duck:** scan the checked-out repository and dependency manifests under the organization's authorized Black Duck configuration. Classify the repository's own code with `LicenseRef-OmniCompass-Evaluation-1.0` and review any unknown-license findings. Do not assume the scanner automatically interprets the custom identifier.
- **FOSSA:** scan with the organization's authorized FOSSA configuration, review the dependency inventory and project-license classification, and map the custom license to the exact root LICENSE terms as supported by the account's policies.
- **Snyk:** scan the project's dependency manifests and lock files with an authorized Snyk organization. Review license findings for third-party packages separately from the proprietary project license; a dependency vulnerability scan is not proof of the project's licensing rights.

Do **not** commit scanner API tokens, organization secrets, or license-server credentials. Do not upload proprietary source or raw benchmark evidence to a third-party scanning service without the owner's approval and an appropriate data-processing agreement. For private code analysis, review each vendor's data handling and retention settings first.
