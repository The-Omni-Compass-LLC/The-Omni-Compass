## What a seat sheet is

One sheet per Millennium Prize problem, each built **outside the frozen engine** and attached to it through an explicit
map. A sheet holds five things:
1. the official problem statement;
2. what Omni-Compass's own mathematics supplies, line by line;
3. what it does not, which must be built from other mathematics;
4. every attack tried, with its result, losses included;
5. a program that recomputes every number.

**Proof levels:**
- **Level 1:** the seat states the target.
- **Level 2:** Omni's law realizes the target through an invariant sector and a surjective, evolution-preserving map.
- **Level 3:** Omni's law implies the target.

No sheet claims a level it has not shown.
